## Phase 12: Pulse-Timing Peripherals & Acoustic Signaling

### 31. Infrared (IR) Remote Carrier Modulation & Protocol Decoding
**Goal:** 38 kHz carrier frequency generation via RMT peripheral, space/mark pulse-width encoding, and NEC/Samsung protocol packet decoding.
```yaml
remote_transmitter:
  pin: GPIO3
  carrier_duty_percent: 50%

remote_receiver:
  pin: GPIO4
  tolerance: 25%

binary_sensor:
  - platform: remote_receiver
    name: "IR Remote Power Key"
    nec:
      address: 0x00FF
      command: 0x45BA
```

### 32. Ultrasonic Distance & Time-of-Flight Flight Timing
**Goal:** Microsecond-precision trigger strobe generation, input capture / interrupt-driven echo pulse duration measurement, and speed-of-sound distance conversion.
```yaml
sensor:
  - platform: ultrasonic
    trigger_pin: GPIO5
    echo_pin: GPIO6
    name: "Sump Pit Water Level"
    update_interval: 2s
    timeout: 3m
```

### 33. RTTTL Melodies & Tone Frequency Synthesis
**Goal:** Ring Tone Text Transfer Language (RTTTL) parsing, pitch-to-frequency lookup table calculation, and dynamic timer PWM frequency sweeping.
```yaml
output:
  - platform: ledc
    pin: GPIO7
    id: buzzer_pwm

rtttl:
  output: buzzer_pwm

button:
  - platform: template
    name: "Play Alert Tune"
    on_press:
      - rtttl.play: "beep:d=4,o=5,b=200:8c6,8g,8c6"
```

## Phase 13: Industrial Buses & Contactless Identification

### 34. Modbus RTU & RS485 Half-Duplex Bus Arbitration
**Goal:** Serial packet framing with silent interval (t3.5) frame delimitation, CRC16-MODBUS checksumming, and hardware direction-control (DE/RE) pin toggling.
```yaml
uart:
  id: modbus_uart
  tx_pin: GPIO21
  rx_pin: GPIO20
  baud_rate: 9600

modbus:
  id: modbus_bus
  uart_id: modbus_uart
  flow_control_pin: GPIO10

sensor:
  - platform: modbus_controller
    modbus_id: modbus_bus
    name: "Active Power"
    address: 0x01
    register_type: holding
    register_address: 0x0012
    value_type: FP32
```

### 35. Contactless RFID/NFC Tag Authentication
**Goal:** I²C/SPI transceiver framing (e.g. PN532), 13.56 MHz contactless polling, anti-collision loops, and ISO 14443A UID payload validation.
```yaml
pn532_i2c:
  id: nfc_module
  i2c_id: i2c0

binary_sensor:
  - platform: pn532
    pn532_id: nfc_module
    uid: "4B-12-8A-3F"
    name: "Access Card Granted"
    on_press:
      - switch.turn_on: door_strike
```

## Phase 14: Complex Actuation, Multiplexing & BLE Central

### 36. Multi-Speed Fan Controller & State Engine
**Goal:** Coordinated speed stepping (low/med/high), duty-cycle table quantization, direction reversing interlocks, and dedicated power switch synchronization.
```yaml
output:
  - platform: ledc
    pin: GPIO3
    id: fan_speed_pwm

fan:
  - platform: speed
    output: fan_speed_pwm
    name: "Ceiling Fan"
    speed_count: 3
```

### 37. Matrix Keypad Scanning & Anti-Ghosting
**Goal:** Multiplexed row-driver strobe cycling, synchronized column sampling, debounced switch matrix decoding, and multi-key lockout.
```yaml
matrix_keypad:
  id: num_pad
  rows:
    - pin: GPIO0
    - pin: GPIO1
  columns:
    - pin: GPIO2
    - pin: GPIO3
  keys: "1234"
  has_diodes: false

binary_sensor:
  - platform: matrix_keypad
    keypad_id: num_pad
    key: "1"
    name: "Keypad Digit 1"
```

### 38. Active BLE Client & GATT Characteristic Polling
**Goal:** Outgoing BLE Central connection management, GATT MTU negotiation, primary service discovery, and characteristic read/notify polling.
```yaml
esp32_ble_tracker:

ble_client:
  - mac_address: "DC:23:4F:91:0A:BC"
    id: ble_sensor_node

sensor:
  - platform: ble_client
    ble_client_id: ble_sensor_node
    name: "Remote Soil Moisture"
    service_uuid: "181A"
    characteristic_uuid: "2A6E"
    update_interval: 60s
```
