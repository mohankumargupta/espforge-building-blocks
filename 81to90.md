## Phase 32: Environmental Radiation, Photometry & Soil Calibration

### 81. Radiation Pulse Counter & Geiger-Müller Tube (CPM to µSv/h)
**Goal:** Microsecond edge-interrupt pulse accumulation from high-voltage discharge tubes, 60-second sliding-window counts-per-minute (CPM) integration, and tube-specific ionizing dose factor conversion (µSv/h).
```yaml
sensor:
  - platform: pulse_counter
    pin:
      number: GPIO4
      mode: INPUT_PULLUP
    name: "Radiation Pulse Count"
    unit_of_measurement: "CPM"
    update_interval: 10s
    filters:
      - multiply: 6 # Convert 10s sample to counts per minute
  - platform: template
    name: "Radiation Dose Equivalent"
    unit_of_measurement: "µSv/h"
    accuracy_decimals: 3
    lambda: |-
      // J305/M4011 tube factor (~0.00812 CPM to µSv/h)
      return id(radiation_pulse_count).state * 0.00812;
```

### 82. High Dynamic Range I²C Ambient Light Sensor (BH1750)
**Goal:** Photodiode electron flow integration, automatic switching between high-resolution and low-resolution optical modes, and direct lux luminous flux calculation.
```yaml
sensor:
  - platform: bh1750
    name: "Ambient Illuminance"
    address: 0x23
    i2c_id: i2c0
    measurement_duration: 69
    update_interval: 10s
```

### 83. Soil Moisture Capacitive Probing & Piecewise Calibration
**Goal:** High-impedance analog frequency-to-voltage sampling, ADC voltage divider linearization, and non-linear multi-point soil dryness-to-saturation curve mapping.
```yaml
sensor:
  - platform: adc
    pin: GPIO0
    name: "Soil Moisture"
    unit_of_measurement: "%"
    update_interval: 30s
    attenuation: 11db
    filters:
      - calibrate_linear:
          - 2.45 -> 0.0   # Completely dry in free air
          - 1.10 -> 100.0 # Submerged in cup of water
      - lambda: |-
          if (x < 0.0) return 0.0;
          if (x > 100.0) return 100.0;
          return x;
```

