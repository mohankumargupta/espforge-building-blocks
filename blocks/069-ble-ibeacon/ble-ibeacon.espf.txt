====================
069 - BLE IBEACON PROXIMITY BROADCASTING

<ble_beacon> is a proposal: the iBeacon payload is a fixed 25-byte array, so
the only missing capability is a <ble> radio that can advertise it in
broadcaster mode.
====================

  <runtime type="blocking" />
