089 - ICMP NETWORK PING AND HOST PRESENCE WATCHDOG

<ping> is a proposal: the runtime exposes TCP clients only, so there is no ICMP
socket and no RTT to measure. The Wi-Fi stack it would ride is real.
====================

  <runtime type="embassy" />

# devices
# services
  <wifi_station id="home" wifi="$radio" ssid="MyNetwork" password="MyPassword" />
