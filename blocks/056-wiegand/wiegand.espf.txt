====================
056 - WIEGAND PROTOCOL DUAL-WIRE ACCESS KEYPAD / RFID

<wiegand> is a proposal. A Wiegand bit is a 50-100 us pulse, so polling cannot
see it: this needs edge capture with microsecond timestamps, the same missing
primitive as the block 017 pulse counter. The door latch is a real <led>.
====================
