## Phase 24: Navigation, Segmented Optics & Sound Modules

### 61. NMEA 0183 GPS Positioning & Sentence Decoding
**Goal:** High-throughput UART stream parsing, `$GPRMC`/`$GPGGA` sentence checksum verification, coordinate extraction, and atomic updates to latitude, longitude, and elevation entities.
```yaml
uart:
  id: gps_uart
  rx_pin: GPIO20
  tx_pin: GPIO21
  baud_rate: 9600

gps:
  id: gnss_module
  uart_id: gps_uart

sensor:
  - platform: gps
    gps_id: gnss_module
    latitude:
      name: "Node Latitude"
    longitude:
      name: "Node Longitude"
    altitude:
      name: "Node Altitude"
    satellites:
      name: "Visible Satellites"
```

### 62. Addressable LED Strip Partitioning & Virtual Zones
**Goal:** Subdividing a single contiguous physical RMT LED buffer into independently controllable logical light entities with non-overlapping index ranges.
```yaml
light:
  - platform: esp32_rmt_led_strip
    id: physical_strip
    pin: GPIO3
    num_leds: 60
    rgb_order: GRB
    chipset: ws2812

  - platform: partition
    name: "Desk Left Zone"
    segments:
      - id: physical_strip
        from: 0
        to: 29

  - platform: partition
    name: "Desk Right Zone"
    segments:
      - id: physical_strip
        from: 30
        to: 59
```

### 63. Serial MP3 Media Player (DFPlayer Mini)
**Goal:** Byte-level UART packet framing with command bytes, parameter words, and checksum validation, folder/track sound triggering, and busy-pin status monitoring.
```yaml
uart:
  id: dfplayer_uart
  tx_pin: GPIO6
  rx_pin: GPIO7
  baud_rate: 9600

dfplayer:
  uart_id: dfplayer_uart
  busy_pin: GPIO10
  id: sound_fx

button:
  - platform: template
    name: "Play Doorbell Chime"
    on_press:
      then:
        - dfplayer.play_folder:
            folder: 1
            file: 1
```

## Phase 25: Power Grid Synchronization & Micro-Timing

### 64. AC Phase-Cutting Dimmer & Zero-Cross Triac Timing
**Goal:** Hardware zero-crossing edge interrupt capture (50/60 Hz), microsecond hardware timer delay dispatch, and narrow gate strobe generation for leading/trailing-edge triac dimming.
```yaml
output:
  - platform: ac_dimmer
    id: light_dimmer
    gate_pin: GPIO3
    zero_cross_pin:
      number: GPIO2
      mode: INPUT_PULLUP

light:
  - platform: monochromatic
    output: light_dimmer
    name: "Filament Chandelier"
```

### 65. Complex Multi-Click Pattern Discrimination Engine
**Goal:** Stateful input edge timing windows, multi-tap counting, debounce handling, and discriminating between single-click, double-click, and long-press-and-hold events.
```yaml
binary_sensor:
  - platform: gpio
    pin:
      number: GPIO4
      mode: INPUT_PULLUP
      inverted: true
    name: "Multi-Function Button"
    on_multi_click:
      - timing:
          - ON for at most 350ms
          - OFF for at most 350ms
          - ON for at most 350ms
          - OFF for at least 200ms
        then:
          - logger.log: "Double-click triggered"
      - timing:
          - ON for at least 1000ms
        then:
          - logger.log: "Long-press hold triggered"
```

## Phase 26: Offline Resilience, Hardware RTCs & Removable Storage

### 66. Battery-Backed I²C Real-Time Clock (DS3231)

```yaml

    address: 0x68

  - platform: ds3231

      name: "RTC Crystal Temperature"
```

### 67. Removable SPI SD Card & FAT32 Telemetry Logging
**Goal:** SPI block-level mass storage initialization, software FAT/FAT32 filesystem drivers, append-only sensor log record streaming, and filesystem flush safety.
```yaml
spi:
  clk_pin: GPIO6
  mosi_pin: GPIO7
  miso_pin: GPIO2

sd_card:
  cs_pin: GPIO10
  id: sd_logger

interval:
  - interval: 10s
    then:
      - lambda: |-
          FILE *f = fopen("/sd/telemetry.csv", "a");
          if (f != NULL) {
            fprintf(f, "%d,%.2f\n", id(sntp_time).now().timestamp, id(room_temp).state);
            fclose(f);
          }
```
