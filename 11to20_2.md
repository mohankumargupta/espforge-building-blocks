## Phase 8: Motion, Actuation & Complex Physical Inputs

### 21. Servos & Calibrated Pulse Width Modulation
**Goal:** Microsecond-precision pulse generation (50 Hz frame), angle-to-duty mapping curves, and smooth target transition slewing.
```yaml
output:
  - platform: ledc
    pin: GPIO3
    id: servo_pwm
    frequency: 50Hz

servo:
  - id: camera_pan
    output: servo_pwm
    min_pulse_width: 500us
    max_pulse_width: 2500us
    transition_length: 500ms
```

### 22. Motorized Covers & Time-Based State Machines
**Goal:** Bidirectional motor interlocks, runtime position estimation via elapsed transit timers, and target position tracking (open/close/stop).
```yaml
cover:
  - platform: time_based
    name: "Living Room Blinds"
    open_action:
      - switch.turn_on: motor_open_relay
    open_duration: 15s
    close_action:
      - switch.turn_on: motor_close_relay
    close_duration: 15s
    stop_action:
      - switch.turn_off: motor_open_relay
      - switch.turn_off: motor_close_relay
```

### 23. Quadrature Rotary Encoders & Knob Inputs
**Goal:** Dual-pin quadrature phase-state decoding, Gray code transition validation, hardware interrupt debounce, and bounded integer value tracking.
```yaml
sensor:
  - platform: rotary_encoder
    name: "Volume Dial"
    pin_a: GPIO6
    pin_b: GPIO7
    resolution: 4
    min_value: 0
    max_value: 100
```

## Phase 9: Multi-Drop & Single-Wire Buses

### 24. 1-Wire Bus & Multi-Drop Temperature Networks
**Goal:** Strict sub-microsecond single-pin bus timing (reset pulse, presence detect, bit-banging), ROM enumeration (Search ROM algorithm), and scratchpad CRC8 validation.
```yaml
one_wire:
  - platform: gpio
    pin: GPIO4
    id: ow_bus

sensor:
  - platform: dallas_temp
    one_wire_id: ow_bus
    index: 0
    name: "Water Tank Temperature"
    update_interval: 15s
```

### 25. SPI Bus & High-Speed Sensor Transceivers
**Goal:** Shared SPI bus master arbitration, clock polarity/phase (CPOL/CPHA) configurations, CS line asserting, and streaming bit conversion.
```yaml
spi:
  clk_pin: GPIO6
  miso_pin: GPIO2
  mosi_pin: GPIO7

sensor:
  - platform: max6675
    name: "Furnace Thermocouple"
    cs_pin: GPIO10
    update_interval: 5s
```

## Phase 10: Local Radio & Peer-to-Peer Protocols

### 26. Bluetooth LE (BLE) Scanner & Presence Tracking
**Goal:** ESP32-C3 NimBLE/BLE controller integration, gap scanning, advertisement packet parsing, MAC filtering, and RSSI tracking.
```yaml
esp32_ble_tracker:

binary_sensor:
  - platform: ble_presence
    mac_address: "AA:BB:CC:DD:EE:FF"
    name: "Key Beacon Presence"
```

### 27. ESP-NOW Peer-to-Peer Messaging
**Goal:** Connectionless 802.11 vendor frame broadcasts, direct device-to-device packet transport without Wi-Fi AP association or router hops.
```yaml
esp_now:

binary_sensor:
  - platform: gpio
    pin: GPIO3
    on_press:
      then:
        - esp_now.send:
            address: "11:22:33:44:55:66"
            message: "DOORBELL"
```

## Phase 11: Closed-Loop Regulation, Synthetic Entities & Diagnostics

### 28. Climate Control & Thermostat Regulation
**Goal:** Two-point/bang-bang thermostat state machine, deadband hysteresis, anti-short-cycle delay timers, and heat/cool action triggers.
```yaml
climate:
  - platform: thermostat
    name: "HVAC Zone Controller"
    sensor: bme_temperature
    min_cooling_off_time: 300s
    min_heating_off_time: 300s
    default_target_temperature_low: 20.0
    default_target_temperature_high: 22.0
    heat_action:
      - switch.turn_on: heater_relay
    idle_action:
      - switch.turn_off: heater_relay
```

### 29. Synthetic Template Entities & Derived Math
**Goal:** Runtime expressions/lambdas compiling into embedded evaluate loops that compute derived metrics from raw physical sensors.
```yaml
sensor:
  - platform: template
    name: "Calculated Dew Point"
    unit_of_measurement: "°C"
    accuracy_decimals: 1
    lambda: |-
      float t = id(room_temperature).state;
      float rh = id(room_humidity).state;
      return t - ((100.0 - rh) / 5.0);
```

### 30. System Health Diagnostics & Hardware Watchdog
**Goal:** Task watchdog timer (WDT) feeds, heap/memory leak tracking, Wi-Fi RSSI reporting, uptime clocking, and programmatic soft-reboot handlers.
```yaml
sensor:
  - platform: uptime
    name: "System Uptime"
    update_interval: 60s
  - platform: wifi_signal
    name: "Wi-Fi RSSI"
    update_interval: 60s

button:
  - platform: restart
    name: "Restart Node"
```
