## Phase 5: Provisioning, Network Transports & Time

### 11. Network Time & Scheduled Automations
**Goal:** SNTP client synchronization, internal wall-clock tracking, timezone offsets, and cron-like scheduled triggers.
```yaml
time:
  - platform: sntp
    id: sntp_time
    timezone: "UTC"
    on_time:
      - seconds: 0
        minutes: 0
        hours: 8
        then:
          - switch.turn_on: daily_switch
```

### 12. Captive Portal & Wi-Fi Provisioning
**Goal:** Fallback AP beaconing on network loss, embedded DNS server for captive portal redirection, and runtime credential storage.
```yaml
wifi:
  ssid: "PrimarySSID"
  password: "PrimaryPassword"
  ap:
    ssid: "FallBack-Hotspot"
    password: "provisioningpass"

captive_portal:
```

### 13. Embedded Web Server & Local REST API
**Goal:** Embedded HTTP daemon, serving static assets, and exposing JSON endpoints for zero-hub direct entity reads and commands.
```yaml
web_server:
  port: 80
  version: 2
  include_internal: false
```

### 14. MQTT Transport & Auto-Discovery
**Goal:** Asynchronous MQTT client, pub/sub topic routing, retain flags, and Home Assistant MQTT auto-discovery JSON schemas.
```yaml
mqtt:
  broker: 192.168.1.100
  port: 1883
  discovery: true
  discovery_prefix: homeassistant
  topic_prefix: test-node
```

## Phase 6: High-Speed Buses & Specialized Peripherals

### 15. Addressable RGB LED Strip (RMT Engine)
**Goal:** Hardware RMT (Remote Control) peripheral driver, precise sub-microsecond pulse timing, RGB color management, and procedural light effects.
```yaml
light:
  - platform: esp32_rmt_led_strip
    rgb_order: GRB
    pin: GPIO3
    num_leds: 30
    rmt_channel: 0
    chipset: ws2812
    name: "Desk Ambient Light"
    effects:
      - pulse:
          name: "Fast Pulse"
          transition_length: 500ms
```

### 16. Hardware UART & Serial Sensor Parsing
**Goal:** Peripheral UART driver, ring-buffered byte streams, packet delimiter framing, and binary/checksum verification for modular sensors.
```yaml
uart:
  id: uart_bus
  tx_pin: GPIO21
  rx_pin: GPIO20
  baud_rate: 9600

sensor:
  - platform: mhz19
    uart_id: uart_bus
    co2:
      name: "CO2 Concentration"
    temperature:
      name: "Sensor Temperature"
    update_interval: 30s
```

### 17. Hardware Pulse Counter & Rate Metering
**Goal:** Dedicated hardware edge counter (PCNT/timer interrupts), glitch filtering, frequency-to-rate computation (e.g., flow rate, energy metering).
```yaml
sensor:
  - platform: pulse_counter
    pin: GPIO4
    name: "Water Flow Rate"
    update_interval: 10s
    filters:
      - multiply: 0.1

## Phase 7: Power Management, Persistence & Graphical UI

### 18. Deep Sleep & Wakeup Triggers
**Goal:** ESP32-C3 RTC power domain control, RTC timer alarms, GPIO wakeup pins, and managing sleep cycles between readings.
```yaml
deep_sleep:
  id: deep_sleep_control
  run_duration: 15s
  sleep_duration: 10min
  wakeup_pin:
    number: GPIO3
    mode: INVERT_WAKEUP
```

### 19. Global State & Non-Volatile Storage (NVS)
**Goal:** Declared typed variables with runtime persistence across power cycles and reboots via flash/NVS key-value storage.
```yaml
globals:
  - id: total_cycles
    type: int
    restore_value: yes
    initial_value: '0'

switch:
  - platform: template
    name: "Increment Cycle"
    turn_on_action:
      - lambda: 'id(total_cycles) += 1;'
```

### 20. Display Buffer & Font Graphics Engine
**Goal:** Framebuffer allocation, font bitmap rasterization, page redraw loops, and dynamic display formatting lambdas over I²C/SPI.
```yaml
font:
  - file: "fonts/Roboto-Medium.ttf"
    id: font_default
    size: 16

display:
  - platform: ssd1306_i2c
    model: "SSD1306 128x64"
    address: 0x3C
    i2c_id: i2c0
    lambda: |-
      it.printf(0, 0, id(font_default), "Node Online");
      it.strftime(0, 30, id(font_default), "%H:%M:%S", id(sntp_time).now());
```
